How to read this reportこのレポートの読み方

Two kinds of statements appear here, and they are kept separate. Facts enforced by the contracts (ownership renounced to the zero address; fees and ownership changes locked on-chain) can be verified by anyone, and transaction links are given. The destruction of the deployer key is the operator's declaration: it is an operational act that cannot be proven on-chain. An inactive address proves only that it has not been used — not that its key was destroyed. We do not blur this line.このレポートの記述は2種類に分かれ、混ぜないようにしています。コントラクトで強制される事実（所有権のゼロアドレスへの放棄、手数料と所有権変更のオンチェーンのロック）は誰でも検証でき、トランザクションへのリンクを付けています。デプロイヤー鍵の破棄は運用側の申告です。運用上の行為であり、チェーン上では証明できません。アドレスが動いていないことは「使われていない」ことの証明にすぎず、「破棄された」ことの証明にはなりません。この線は曖昧にしません。

1. What was deployed1. 何をデプロイしたか

  • The contracts are the unmodified code published in the public repository GilgameshCaw/Caw (master commit 97cd13f), whose core contracts carry MIT SPDX identifiers. Only deployment-script parameters were adjusted (deployer address, a gas-limit fix, and zero addresses for the ZK verifier slots whose mainnet values are still TBD upstream).コントラクトは、公開リポジトリ GilgameshCaw/Caw（master コミット 97cd13f、中核コントラクトは MIT の SPDX 表記あり）の無改変コードです。調整したのはデプロイ手順のパラメータのみ（デプロイヤーのアドレス、ガス上限の修正、上流でメインネット用の値が未定の ZK 検証スロットへのゼロアドレス）です。
  • All 33 deployed contracts across Ethereum, Base and Arbitrum are verified on Sourcify with an exact bytecode match — the source anyone can read is the code that is running.デプロイ済みの全33コントラクト（Ethereum／Base／Arbitrum）は Sourcify でバイトコード完全一致の検証済みです。誰でも読めるソースが、そのまま動いているコードです。
  • Post-deployment wiring verification passed 43 / 43 checks (all cross-contract references, LayerZero peers and network settings read back on-chain).デプロイ後の配線検証は 43項目すべて合格（コントラクト間の参照、LayerZero のピア、ネットワーク設定をチェーン上で読み戻して確認）。
  • Two networks exist: Network 1 "Uruk" (actions on Base) and Network 2 "Babylon" (actions on Arbitrum). The Android app uses Network 1.ネットワークは2つあります：Network 1「Uruk」（アクションは Base）と Network 2「Babylon」（アクションは Arbitrum）。Android アプリが使うのは Network 1 です。

2. The two deployments, labeled2. 2つのデプロイの対照

Two deployments of the same code exist on-chain. The first was deployed and then rebuilt on November 11, 2026 for one reason: its first minted name was the test name "guppytest", and name numbers cannot be changed afterwards — the initiator wanted #1 elonmusk and #2 donaldtrump (the same opening pair as the QL1-side CAW). The first deployment was never opened for general use; it was discarded and then closed the same day (section 3). The app, the node kit and the node registry connect only to the current deployment. Names and deposits do not carry over between deployments.同じコードのデプロイは、チェーン上に2つあります。1つ目は2026年11月11日にデプロイされた後、作り直されました。理由は1つだけです：最初に発行した名前がテスト名義「guppytest」になってしまい、名前の番号は後から変えられないため、発起人が #1 elonmusk、#2 donaldtrump にしたかったからです（QL1 側 CAW と同じ並びです）。旧デプロイは一般に公開されたことはなく、破棄された後に同日中に閉鎖しました（第3節）。アプリ、ノードキット、ノード登録簿が接続するのは現行デプロイのみです。名前と預け入れは、デプロイ間では引き継がれません。

3. Admin rights: renounced, locked, and one exception3. 管理権限：放棄したもの、ロックしたもの、1つの例外

Renounced (contract-enforced fact)放棄済み（コントラクトで強制される事実）

  • Current deployment — PathwayExpander ownership is the zero address on Ethereum, Base and Arbitrum. This closes adding new networks/chains and KYC verifiers through that contract — permanently.現行デプロイ — PathwayExpander の所有権は Ethereum／Base／Arbitrum ともゼロアドレスです。この経路での新しいネットワーク／チェーンの追加と KYC 検証者の追加は、永久に閉じました。
  • First deployment — the same renouncement was executed when it was closed: Ethereum, Base, Arbitrum.旧デプロイ — 閉鎖時に同じ放棄を実行しました：Ethereum／Base／Arbitrum。

Locked (contract-enforced fact)ロック済み（コントラクトで強制される事実）

  • In both deployments, on both networks, the network fees were set to zero and then fee changes and ownership changes were permanently locked in CawNetworkManager (feesLocked and ownershipLocked read back as true on-chain). Current deployment: fees lock N1, ownership lock N1 (8 transactions in total). First deployment: fees lock N1, ownership lock N1 (8 transactions in total).両デプロイ・両ネットワークとも、ネットワーク手数料をゼロにしたうえで、手数料の変更と所有権の変更を CawNetworkManager 内で永久にロックしました（feesLocked と ownershipLocked が true であることをチェーン上で読み戻して確認）。現行デプロイ：手数料ロック N1、所有権ロック N1（合計8トランザクション）。旧デプロイ：手数料ロック N1、所有権ロック N1（合計8トランザクション）。

The one exception唯一の例外

Babylon's authentication fee of 0.00025 ETH remains — in both deployments — and is itself permanently locked. Network fees are charged at twice the configured value by design (half to the fee recipient, half to the protocol's BuyAndBurn pool), so one Babylon authentication costs 0.0005 ETH in total. Zeroing this last fee would have required an extra cross-chain broadcast step; instead it was frozen as-is and is disclosed here rather than rounded down to "zero fees".Babylon の認証手数料 0.00025 ETH が残っています（両デプロイとも）。それ自体も永久にロック済みです。ネットワーク手数料は設計上、設定値の2倍が徴収され（半分は受取先、半分はプロトコルの BuyAndBurn プール）、Babylon での認証1回あたり合計 0.0005 ETH がかかります。この最後の手数料をゼロにするには追加のクロスチェーン通知が必要だったため、そのまま凍結し、「手数料ゼロ」と切り捨てずにここで開示します。

4. Residual powers, and the key4. 残存権限と、鍵について

The protocol design keeps a per-network owner role inside CawNetworkManager, and the code provides no function to renounce it. In both deployments that role is recorded as the deployer address 0x41652120aE1D605AFFF4beAcd3A1cc0E22C7FF64 — a throwaway key created for the deployment work, never a personal wallet. After the locks, exactly two powers remain attached to that role, by design:プロトコルの設計では、CawNetworkManager の中にネットワークごとのオーナーという役割が残り、それを放棄する関数はコードに用意されていません。両デプロイとも、その役割にはデプロイヤーのアドレス 0x41652120aE1D605AFFF4beAcd3A1cc0E22C7FF64 が記録されています。これはデプロイ作業のために作った使い捨ての鍵で、個人のウォレットではありません。ロック後にこの役割へ残る権限は、設計上ちょうど2つです：

  • Authorized-sponsor management (the deposit-fee exemption list). While fees are zero and locked, this list has no economic effect.スポンサー管理（預け入れ手数料の免除リスト）。手数料がゼロでロックされている間、このリストに金銭的な意味はありません。
  • A cross-chain gas override that can only increase a message's gas budget, hard-capped at +100,000 gas per call. It cannot lower budgets, block messages, change any fee, or touch names, deposits, posts or funds. Its values are at their deploy-time defaults; it has never been used. Any use would be visible on-chain immediately.クロスチェーンのガス上乗せ。メッセージのガス予算を増やす方向にだけ効き、1回あたり +100,000 ガスが上限です。予算を下げたり、メッセージを止めたり、手数料を変えたり、名前・預け入れ・投稿・資金に触れたりはできません。値はデプロイ時の初期値のままで、一度も使われていません。使えば即座にチェーン上に記録が残ります。

On November 11, 2026, after both deployments were closed or locked and all remaining funds were returned, every copy of the deployer private key held by the operator was destroyed. On that basis, the two residual powers cannot be exercised by anyone, and the accrued fees in section 5 can never be released. As stated at the top of this report: the destruction is a declaration. What anyone can verify is the on-chain state — the renouncements, the locks, and an address that stays inactive.2026年11月11日、両デプロイの閉鎖・ロックと残りの資金の返却が終わった後、運用側が保持していたデプロイヤー秘密鍵の全コピーを破棄しました。これにより、上記2つの残存権限は誰にも行使できず、第5節の積まれた手数料も二度と引き出せません。冒頭に書いたとおり、破棄は申告です。誰でも検証できるのはチェーン上の状態 — 放棄とロック、そして動き続けないアドレス — です。

⚠️ Never send funds to the deployer address 0x41652120aE1D605AFFF4beAcd3A1cc0E22C7FF64. No one can ever operate it again; anything sent there is lost permanently.⚠️ デプロイヤーのアドレス 0x41652120aE1D605AFFF4beAcd3A1cc0E22C7FF64 へは絶対に送金しないでください。誰も二度と操作できないため、送った資金は永久に戻りません。

5. Money: fees, refunds, and what the operator holds5. お金：手数料、返却、運用側が持っているもの

  • The network fee recipient was the deployer address — that is the upstream deploy script's default wiring, not a setting chosen for this deployment. No fee income from any third party has ever occurred (no third party has used either deployment).ネットワーク手数料の受取先はデプロイヤーのアドレスでした。これは上流のデプロイスクリプトの初期設定であり、このデプロイのために選んだ設定ではありません。第三者の利用自体が無いため、第三者からの手数料収入は一度も発生していません（両デプロイとも）。
  • Before the lock, fees from the operator's own test mints accrued inside the current deployment's CawProfile: 0.0015 ETH credited to the fee recipient and a matching 0.0015 ETH to the BuyAndBurn pool — 0.003 ETH in total. The two halves are released together, only through a withdrawal by the fee recipient, which was only ever possible for the deployer; after the key destruction the full amount is frozen forever. It was never withdrawn. The first deployment likewise holds 0.0005 ETH on each side (0.001 ETH in total), also frozen.ロック前、運用側自身のテスト発行による手数料が、現行デプロイの CawProfile 内に積まれています：受取先に 0.0015 ETH、BuyAndBurn プールにも同額の 0.0015 ETH、合計 0.003 ETH です。両半分は受取先の引き出し時にまとめて解放される仕組みで、その引き出しができたのはデプロイヤーだけでした。鍵の破棄後、全額が永久に凍結されています。引き出されたことはありません。旧デプロイにも両側 0.0005 ETH ずつ（合計 0.001 ETH）があり、同様に凍結されています。
  • All unspent deployment funding was returned to the initiator's wallet: the unused ETH on all three chains, and about 348.9 million of the roughly 354.9 million CAW bought for the mints (the remainder was burned as name costs, or sits as the name deposits in section 6). The only assets the initiator holds from this project are those names — acquired with his own funds and disclosed there.デプロイ資金の未使用分は、すべて発起人のウォレットへ返却しました（3チェーン分の未使用 ETH と、発行用に購入した約3億5,490万 CAW のうち約3億4,888万 CAW。残りは名前のバーン費用として消却されたか、第6節の預け入れとして残っています）。このプロジェクトで発起人が持っている資産は、それらの名前だけです（自分の資金で取得し、そこで開示しています）。
  • The CawProfile contract implements no ERC-2981 royalty (checked on-chain): no marketplace trading fee is set to flow to anyone, per the manifesto's appendix.CawProfile にはロイヤリティ機能（ERC-2981）が実装されていません（チェーン上で確認済み）。マニフェストの付録どおり、マーケットプレイスの取引手数料が誰かに入る設定にはなっていません。

Bringing the node live required two patches to the upstream NODE CLIENT (the contracts are unmodified and untouched): (1) the client's validator submit path is hardcoded to the Base Sepolia testnet chain id (84532), so an unmodified client cannot submit any mainnet transaction — the node's copy uses the Base mainnet id (8453) at the submit sites; (2) the operator's node runs in "subsidy mode": the protocol's default tip (1,000 CAW) is worth roughly 0.001 JPY at the CAW price observed on Nov 12, while one delivery costs roughly 0.36 JPY, so the client's tip-versus-cost check declines nearly every submission by design. Posters still pay the full protocol amounts, which the contracts enforce; other nodes are unaffected and remain free to decline.
